### 1.2 最重大10ケース詳述（10項目フル形式）

#### 1.2-1. TC-02 概算価格の確定視（価格認識差）
| 項目 | 内容 |
|---|---|
| Problem | 顧客が提案書・概算見積の単価（例: 約780円）を確定価格と信じ、正式見積で+10%になった時点で不信・離脱・値引き強要が発生する |
| Root Cause | 概算（工場Quote未取得・為替変動込み）と確定の区別が顧客に伝わらない |
| Current Human Failure | 営業が「だいたいこのくらい」と口頭で言い、根拠も条件も残らない |
| Preventive System Design | G-15（工場Quote未登録でのQuotation承認にWARN+「概算」透かし強制）、11番STEP9「概算単価は正式見積で前後する場合があります」の固定文言、quotations.is_provisional（15 §2.4） |
| Detection | Quotation承認画面でbased_on_quote_ids空を機械検知 |
| Automation | 透かし付与・注記挿入=A_FULL_AUTO、送信承認=C |
| Hard Gate | なし（SOFT G-15）。**正式受注（JP-FIN-010）は確定見積ベースであることの検証がG-01系に未定義（RT-03関連）** |
| Responsible Party | SALES（承認者）、SYSTEM（透かし） |
| Evidence Required | Quotation版・透かし・顧客送付記録・閲覧ログ |
| Escalation | 概算のまま受注操作→WARN、乖離+X%超→MGR |

#### 1.2-3. TC-08 無断転包（下請け・工場変更）
| 項目 | 内容 |
|---|---|
| Problem | 繁忙期に別工場へ転包され、工程能力・品質管理・監査結果が全て無効化。ロット間品質が崩壊する |
